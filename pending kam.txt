### 1. Premium Hero Section

* Support Icon
* "Contact Support"

### 2. Issue Type

* Bug Report
* Feature Request
* Notes Issue
* AI Assistant Issue
* Community Issue
* Account Problem
* Other

---

### 3. Subject Field

Required.

Examples:

* App Crash
* Unable to Download Notes
* AI Not Responding

---

### 4. Message Field

Required.

Minimum 20 characters.

Maximum 1000 characters.

Display live character counter.

---

### 5. Support Email

Display

[support@studysphere.app](mailto:support@studysphere.app)

User should be able to tap to copy/open email.

---

### 6. Send Button

Show loading animation while sending.

Disable button during upload.

After success

Show beautiful success dialog instead of only a SnackBar.

---

### 7. Firestore Integration

Create

supportTickets

collection.

Each ticket should contain:

* userId
* userName
* email
* issueType
* subject
* message
* status (Pending)
* createdAt

Only ONE Firestore write per ticket.

No unnecessary reads.

---

### 8. Validation

Validate:

* Empty Issue Type
* Empty Subject
* Empty Message
* Minimum message length

---

### 9. Performance

Keep the screen lightweight.

Do NOT fetch unnecessary Firestore data.

Do NOT create realtime listeners.

Do NOT use StreamBuilder.

Only write data when the user presses Send.

### 10. UI

Follow the existing StudySphere design system.

Use existing:

* AppColors
* AppTextStyles
* Buttons
* Cards
* Theme

Maintain consistency with the Home Screen.
